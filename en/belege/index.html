03 / Juri-Halveth/halveth-unreal

Validate progress before accepting it

Problem

A damaged save must not partially overwrite valid state.

Input

A C++ state model for knowledge, recipes and progress, with deliberately modified import candidates.

Result

Import validates the candidate before applying it. The linked CI run succeeded; its pipeline compiles portable tests with GCC and MSVC. Compiled and executed locally with Clang on 20 Oct 2026: 18,008 knowledge checks and the layout test passed.

Counterexample

RejectSave alters individual fields. RejectUnchanged then requires the exported state to equal the pre-rejection state exactly.

Reuse

Transactional state admission in games and local applications.

Check scope

This evidence covers the portable C++ core. It is not an Unreal Engine build, performance benchmark or graphics acceptance test.

Check type: LOCAL_CPP_TESTS
