Inspect a reproducible source packet

Problem

Node and browser consumers need the same packet bytes and integrity contract.

Input

A source packet with content, metadata and digest, plus deliberately altered test inputs.

Result

The shared parser and counterexamples are directly accessible. The local full-suite run passed 99 JavaScript and 46 Python tests (20 Oct 2026; Node 24.18.0, Python 3.14.6).

Counterexample

Tests alter packet content and bindings. Changed bytes must fail the integrity check.

Reuse

A starting point for local imports and inspectable research artifacts.

Check scope

The 145 tests cover the whole lab. They verify implemented model contracts, not the truth of imported content.

Check type: LOCAL_MODEL_TESTS

02 / Juri-Halveth/halveth-scarlet

Make an interaction visible and reversible

Problem

A visual idea needs direct controls and an observable state.

Input

A click in Singularity Cannon; the field counter and Undo control expose state.

Result

Observed in the browser on 20 Oct 2026: firing creates a singularity and enables Undo. The homepage includes an actual browser capture.

Counterexample

Compare the empty state, a fired field and Undo. Linked source-state tests separately check artifact binding; they are not visual acceptance tests.

Reuse

Interactive explanations, designed simulations and interfaces with visible state.

Check scope

The live capture has no verified build digest. The pinned source and successful deploy run are separate evidence. This is a graphic simulation.
