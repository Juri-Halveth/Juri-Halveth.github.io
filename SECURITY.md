# Security policy

## Reporting a security issue

Please report suspected vulnerabilities privately to **security@halveth.de**.
Include the affected repository and revision, the smallest safe reproduction,
the observed result, and the security boundary you believe is affected. Please
do not include live credentials, access tokens, personal data, or unrelated
system files.

Avoid public issue reports containing exploit details until we have had a
chance to review the report. Do not test against GitHub, linked services,
other users, or infrastructure you do not own or have explicit authorization
to assess. A repository link or local checkout does not grant authority over
those systems.

This repository does not promise a response time, bounty, compensation, or
acceptance of a report. We will assess the specific evidence and coordinate a
reasonable next step where possible.

## Scope

This policy covers code and workflows maintained in this repository. Linked
repositories, GitHub itself, external dependencies, and third-party services
keep their own security policies and authorization requirements.
