10 Module. Ein lokaler Prüfweg.

Das Forschungslabor bündelt JavaScript- und Python-Module mit ihren Tests. Bildvergleich, Quellenpakete, Lichtbrechung und explizite Zustandsmodelle sind einzeln zugänglich.

git clone https://github.com/Juri-Halveth/halveth-forschungslabor.git
cd halveth-forschungslabor
git checkout 07417d3cdadda426c2b51cc98bcbae72d7b5d651
npm test

Die Prüfungen beziehen sich auf die implementierten Modelle und mitgelieferten Gegenbeispiele. Ein lokaler Test ersetzt keine externe Produktprüfung.
