TIEFE LESESPUR

Nicht nur sehen.
Den Modellvertrag lesen.

Jede Karte bindet eine Darstellung an ihren Zweck. Sie bleibt eine eigenständige Modelloberfläche – ohne eine physische Messung oder eine allgemeine Weltbehauptung daraus zu machen.

01 / AUSGANG

Erste Regel · Plus / Minus

Die Oberfläche beginnt mit zwei gegenläufigen, gleichwertig dargestellten Phasen. Erst die sichtbare Kopplung erzeugt die Mitte. Der Code modelliert eine Beziehung zwischen gezeichneten Kurven; er setzt keine Teilchenerzeugung voraus.

Darstellung
zwei sinusförmige Wege, ein Kopplungsring, drei Knoten
Offene Kante
Welche messbare Erhaltung oder Symmetrie würde eine konkrete physikalische Hypothese tragen?

02 / KONTAKT

Wellenfeld · erster Kontakt

Mehrere Bahnen nähern sich, schwingen in der Begegnung und beruhigen sich im Rhythmus. Die Animation verwendet nur mathematisch definierte Phasen und Dämpfung; sie ist eine Lesefläche für Relation und Übergang.

Darstellung
sechs Phasenbahnen, wandernde Punkte und ein Kontaktkern
Offene Kante
Eine reale Kettenreaktion braucht beobachtbare Größen, Messfenster und ein Gegenmodell.

03 / ANSICHT

Dimensionen · Layer-Live-Modell

Hier sind Zeit, Drehung und Zoom Bedienachsen einer Ansicht. Die Szene macht sichtbar, wie sich ein Objekt über mehrere Perspektiven ordnen lässt. Sie führt damit keine Messung zusätzlicher physischer Dimensionen aus.

Darstellung
verschachtelte Ringe, Bahnen und Knoten
Offene Kante
Eine Dimension im fachlichen Sinn benötigt unabhängige Koordinaten und eine definierte Messbrücke.

04 / ÜBERGANG

Schichten · Zwischenräume

Das Modell zeigt Ebenen als getrennte Horizonte und die Zwischenräume als eigene Orte der Veränderung. Seine Zahlen und Abstände sind bewusst Darstellungsgrößen, nicht Messwerte von Naturprozessen.

Darstellung
sieben Schichten, Durchläufe und Übergangslinien
Offene Kante
Welche Daten beschreiben Zustand, Übergang und Unsicherheit ohne sie zu vermischen?

05 / TIEFE

Strudel · räumliche Projektion

Die räumliche Wirkung entsteht in einer zweidimensionalen Projektion. Mehrere Spiralen, Größen und Verschiebungen bilden eine navigierbare Tiefe, ohne daraus Raumzeitmessung oder eine zusätzliche Naturdimension zu behaupten.

Darstellung
vier perspektivische Spiralen mit verdichteten Knoten
Offene Kante
Welche Invarianten überstehen Perspektivwechsel und welche sind bloße Erscheinung?

06 / ZEIT

Strudel · Zeitbahn

Eine Spirale ordnet Stationen, Rückwege und offene Übergänge. Die Bahn ist eine Modellchronologie; eine reale Zeitbehauptung würde eigene Ereigniszeiten, Beobachtungsfenster und Coverage benötigen.

Darstellung
eine fortlaufende Spirale, neun Stationen und zwei Referenzringe
Offene Kante
Welche Daten könnten eine hypothetische Zeitbahn von einer ansprechenden Narration unterscheiden?

07 / VERFEINERUNG

Zwischenraum · Teilung

Die Teilung greift eine endliche Strecke immer wieder auf. Jede Stufe ist adressierbar, während der Rahmen erhalten bleibt. Das ist eine ausführbare Visualisierung von dₙ = L / 2ⁿ.

Darstellung
64 gleich große Teilintervalle, pulsierende Mittelpunkte und ein gemeinsamer Rahmen
Offene Kante
Bei welcher Skala ändert sich der passende Begriff von Abstand, Kontakt oder Grenze?

08 / AUSSCHNITT

Beobachterraum

Quelle, Blickrichtung und Ausschnitt bleiben getrennt. Das Modell zeigt, dass eine sichtbare Ansicht nicht automatisch den gesamten zugrunde liegenden Zustand enthält.

Darstellung
Quelle, Blickknoten, neun Sichtlinien und ein dynamischer Ausschnittring
Offene Kante
Welche Quelle und welches Messverfahren trennen eine Beobachtung von ihrer Deutung?

QUELLE · CODE · PRÜFUNG

Die Karte hat
einen lesbaren Kern.

Die Szenen liegen in einer kleinen, DOM-freien Rechenebene. Sie erzeugt nur Zeichenprimitive für die Browseransicht. Der Testlauf prüft eindeutige Modell-IDs, endliche Zeichenwerte über einen ganzen Animationszyklus und die lückenfreie rekursive Teilung des Einheitsintervalls.
