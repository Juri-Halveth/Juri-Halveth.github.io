Die vier Zustände eines Belegs

Quellcode vorhanden: Eine Implementierung ist lesbar. Im Modell ausgeführt: Ein festgelegter Versuch wurde mit benannten Eingaben gerechnet. Extern gemessen: Daten stammen aus einer unabhängigen Beobachtung. Hypothese: Eine Annahme wird untersucht, nicht als Ergebnis vorausgesetzt.

Diese Zustände sind keine aufsteigende Rangliste. Ein Test kann ein Programmverhalten zeigen, ohne eine naturwissenschaftliche Aussage zu bestätigen.

Warum ein grüner Test kein ganzes System absichert

Ein Test prüft einen benannten Vertrag. Syntaxprüfung, numerische Stabilität, Darstellung und Sicherheit sind verschiedene Verträge. Die Wärme-Gegenprobe zeigt das: Eine Energiegleichung kann korrekt bilanziert sein, obwohl Wärme noch keine Druckkraft verursacht.
