FORTUNA · Сравнение вариантов

Откройте «Коллектив /70», введите варианты и нажмите «Выбрать вместе». Страница показывает входные данные, веса и решения профилей. В пространстве находятся 69 персонажей с заданными правилами; выбор использует 70 профилей.

  • docs/index.htmlИнтерфейс
  • docs/preview.mjsСцена
  • docs/curiosity.mjsИсследование и движение
  • docs/collective.mjsРасчёт
  • docs/collective-panel.mjsВвод и результаты
  • docs/collective-members.json70 профилей
  • docs/object.jsonОбъект и происхождение
  • docs/NOTICE.mdПроисхождение компонентов

Где находятся проверки?

  • docs/curiosity.test.mjs69 фигур: исследование, продолжение движения и стабильные входные данные

Выполнить в соответствующем репозитории

Что означают числа?

Пройдены 12 тестов модели: семь проверок поведения и пять проверок коллективного выбора. Ещё три локальные DOM-проверки охватывают немецкий, английский и русский языки.

Scarlet · Земля, персонажи и источники

Портал объединяет изображение Земли, источники, профили персонажей и исследовательские страницы. В entities/ каждое имя открывает свой профиль; там же находится интерактивное пространство персонажей.

Открыть интерфейс ↗Открыть репозиторий ↗

За что отвечает каждый файл?

  • index.htmlПортал
  • entities/index.htmlКаталог персонажей
  • assets/universe-data.jsИмена и профили
  • assets/entity-world.mjsПространство персонажей
  • assets/entity-world-motion.mjsТраектории и время
  • assets/entity-world-scene.mjsОтображение сцены
  • tools/build_profiles.mjsГенерация профилей
  • tools/build_site.mjsСборка публичного сайта
  • tools/check_links.mjsПроверка локальных ссылок

Где находятся проверки?

  • tests/entity-roaming.test.cjs69 маршрутов, движение ног и ограниченная загрузка мира

node --test tests/*.test.cjs tests/*.test.mjs

Что означают числа?

Собраны 86 HTML-страниц и проверены 1 844 локальные ссылки href/src/poster. Затем пройдены 232 JavaScript-теста. Это три разных показателя: страницы, проверенные ссылки и тесты.

GIT BASH · NODE.JS 24

Проверить все пять разделов через Git Bash

HUB.sh использует этот репозиторий и четыре указанных каталога исходников. Он выполняет сборки и тесты, затем сохраняет новую локальную квитанцию в .space-local/. Команды ниже получают публичные исходники и устанавливают существующие зависимости проверок.

git clone https://github.com/Juri-Halveth/Juri-Halveth.github.io.git hub
mkdir hub-quellen
git clone https://github.com/Juri-Halveth/fortuna.git hub-quellen/fortuna
git clone https://github.com/Juri-Halveth/halveth-scarlet.git hub-quellen/halveth-scarlet
git clone https://github.com/Juri-Halveth/lernstudio.git hub-quellen/lernstudio
git clone https://github.com/Juri-Halveth/mein-lernportal.git hub-quellen/mein-lernportal
(cd hub && npm ci --ignore-scripts --no-audit --no-fund)
(cd hub-quellen/lernstudio && npm ci --ignore-scripts --no-audit --no-fund)
(cd hub-quellen/mein-lernportal && npm ci --ignore-scripts --no-audit --no-fund)
bash hub/HUB.sh verify hub-quellen

Опубликованный оператор — переносимая версия прежнего локального процесса. Числа выше относятся к более раннему запуску с указанным временем.
